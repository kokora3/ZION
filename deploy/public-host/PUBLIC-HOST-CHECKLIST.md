# Public-host pilot checklist

D2A validates repository and local Docker behavior only. Real-host boxes below intentionally remain unchecked until D2B.

- [x] Shared G1 GenesisID verified in repository and local simulation
- [ ] Linux host provisioned
- [ ] Stable public address assigned
- [ ] SSH key access works from an operator address
- [ ] Docker Engine and Compose plugin installed from an official source
- [ ] Host/provider firewall reviewed without locking out SSH
- [ ] Public hostname configured, if used
- [ ] Pinned ZION D1 image made available through the chosen trusted channel
- [ ] `deploy.sh --check` passes on the host
- [ ] ZION deployment started
- [ ] NetworkID is `zion-alpha-1`
- [ ] GenesisID is `72ef0c7816d64255fc7b1da266c6a5b5ca345dd89cba2423fc8cfc8b4d1a61c6`
- [ ] Roles are exactly NORMAL + BOOTSTRAP
- [ ] Validator authorization is false and no validator material is present
- [ ] PeerID recorded
- [ ] UDP 42000 (or the explicitly selected external P2P port) reachable from the Internet
- [ ] TCP 42001 API/metrics not publicly reachable
- [ ] Copyable bootstrap multiaddr generated by `status.sh`
- [ ] Windows NORMAL config uses that authenticated `/p2p/<PeerID>` multiaddr
- [ ] Windows NORMAL connects without inbound port forwarding
- [ ] Container restart retains PeerID and StateHash
- [ ] Container recreation/update retains PeerID, StateHash, and objects
- [ ] Host reboot retains PeerID and StateHash
- [ ] Windows reconnects after host restart
- [ ] Board synchronization observed
- [ ] Object fetch observed
- [ ] Canonical state synchronization observed
- [ ] Resource use recorded for D2B/D3
- [ ] Encrypted sensitive node-data backup tested and access-restricted
