# ADR-0082: Phase 13 Freezes the ZION v0.1 Minimum Decentralized Product Scope

## Status

Accepted.

## Decision

Freeze the implemented v0.1 protocol surface after final acceptance. Phase 13 closes concrete integration, recovery, observability, security, packaging, and documentation gaps but adds no wallet, economic system, proof-of-human, relay, DHT, light client, large-object, execution, or central-service feature.

## Consequences

Compatibility changes after this release require a new explicit protocol/schema decision. Deferred capabilities remain roadmap items and are not implied by the alpha release.
